# Awesome Design Systems

A curated list of awesome design systems from [alexpate/awesome-design-systems](https://github.com/alexpate/awesome-design-systems).

**What is a design system?**
> A design system is a collection of documentation on principles and best practices, that helps guide a team to build digital products. They are often embodied in UI libraries and pattern libraries, but can extend to include guides on other areas such as 'Voice and Tone'.

**Source**: https://github.com/alexpate/awesome-design-systems

## When to Use This Skill

- Seeking **inspiration** for your own design system or component library
- Looking up how major companies handle **UI components**, **Voice & Tone**, and **Design Kits**
- Finding open-source **source code** for major UI design systems (React, Vue, HTML/CSS, etc.)
- Researching best practices in UI architecture, accessibility, and documentation

## Using Design Systems in Your Work

When approaching a UI problem, you can consult these systems to see how industry leaders solve similar challenges:
1. **Component Patterns**: How are date pickers, complex tables, or navigation bars structured?
2. **Accessibility (a11y)**: How are ARIA labels, focus states, and keyboard navigation implemented?
3. **Tone of Voice**: How do companies communicate errors, success states, or empty states to users?
4. **Theming & Tokens**: How are design variables (colors, spacing, typography) abstracted into tokens?
