# ورشة فن — Brand System

**One sentence:** A warm Arabic art-studio brand for Baghdad craft workshops — canvas cream paper, forest olive, honey gold, and terracotta on calligraphic Aref Ruqaa + Tajawal.

## Tokens (OKLch-oriented aliases)

| Role | Hex | Notes |
|------|-----|-------|
| `--bg` | `#EFE7D6` | Warm canvas paper |
| `--surface` | `#F6F0E2` | Raised cream |
| `--fg` | `#3A2E1C` | Warm ink |
| `--muted` | `#8A7A5C` | Dim meta |
| `--border` | `rgba(93,74,45,0.18)` | Soft brown edge |
| `--accent` | `#4E5A2E` | Deep forest olive |

## Type

- **Display:** Aref Ruqaa, Tajawal, Georgia, serif  
- **Body:** Tajawal, Segoe UI, Tahoma, sans-serif  
- **Mono:** system mono  

## Posture (3–5 rules)

1. Design RTL-first; English is secondary.
2. One olive primary action per view cluster; honey for underlines/stats; coral for price/category.
3. Cards feel handmade — soft shadow, slight hover tilt, photo-led.
4. Prefer real craft photography over icons or illustrations.
5. Never default to purple gradients, glass, or cool SaaS greys.
