# Design Resources for Developers

A curated collection of design and UI resources from [bradtraversy/design-resources-for-developers](https://github.com/bradtraversy/design-resources-for-developers). This skill provides quick access to the best free design assets, tools, and libraries for web developers.

**Source**: https://github.com/bradtraversy/design-resources-for-developers

## When to Use This Skill

- Finding **free design assets** (icons, illustrations, photos, videos)
- Selecting **color palettes** and gradient tools
- Choosing **fonts** and typography tools
- Picking **UI component libraries** for React, Vue, Angular, Svelte
- Finding **CSS frameworks** and animation libraries
- Getting **design inspiration** and mockup tools
- Selecting **favicon generators** and image compression tools
